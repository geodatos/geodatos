Para actualizar la web:
1. Descomprime el ZIP.
2. Abre https://github.com/geodatos/geodatos
3. Pulsa Add file → Upload files.
4. Sube `index.html` y `logo.png` desde la carpeta descomprimida.
5. Confirma con Commit changes.
6. Espera unos minutos y actualiza https://geodatos.github.io/geodatos/

Los dos archivos deben quedar en la raíz del repositorio.
