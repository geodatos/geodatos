# GEODATOS — sitio web gratuito con GitHub Pages

Este sitio es una página estática en HTML y CSS. No necesita pagar hosting ni instalar programas para publicarla.

## Antes de publicarla
1. Abre `index.html` en un editor de texto (por ejemplo, Bloc de notas o Visual Studio Code).
2. Busca `549XXXXXXXXXX` y reemplázalo por tu número de WhatsApp en formato internacional, solo números. Para Argentina suele comenzar con `549` seguido del código de área y número, sin `+`, espacios ni guiones.
3. Busca `tuemail@ejemplo.com` y reemplázalo por tu correo real.
4. Guarda el archivo.

## Publicarla gratis en GitHub Pages
1. Crea una cuenta en https://github.com si todavía no tienes una.
2. En GitHub, pulsa **New repository**.
3. Ponle un nombre, por ejemplo `geodatos-web`. Puedes dejarlo como **Public**.
4. Pulsa **Create repository**.
5. Dentro del repositorio, selecciona **Add file → Upload files**.
6. Sube `index.html` y `README.md`, y pulsa **Commit changes**.
7. Abre **Settings → Pages**.
8. En **Build and deployment**, elige **Deploy from a branch**.
9. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
10. Espera unos minutos. En esa misma sección aparecerá la dirección pública del sitio.

## Cambios posteriores
Cuando quieras modificar textos o datos de contacto, abre `index.html`, edítalo y vuelve a subirlo al repositorio reemplazando el archivo. GitHub Pages actualizará la web.

## Importante
- GitHub Pages es adecuado para una web informativa como esta.
- No incluye un formulario que almacene consultas. Por ahora, los botones llevan a WhatsApp y correo.
- No publiques datos privados de clientes, archivos de obra ni credenciales.
- La web usa textos y diseño editables; puedes cambiar colores, servicios y secciones en `index.html`.
